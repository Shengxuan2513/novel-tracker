# 阅读 3.0 (Legado) 移动端客户端配套

本目录用于存放移动端「阅读 3.0 (Legado)」官方纯净安装包。

- 推荐版本：`legado-3.26.100113-huaji-arm64-v8a-release.apk`
- 适用机型：ARM64 架构主流 Android / 鸿蒙设备（如华为 Mate 30E Pro 5G、小米、OPPO、vivo 等）
- 官方开源上游：[huajideshutiao/legado](https://github.com/huajideshutiao/legado)

启动 Web 服务后（`python cli.py web`），可通过浏览器访问 `http://<lan_ip>:5000/legado.apk` 直连下载。
